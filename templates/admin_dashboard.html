🧹 Data & Maintenance

A scheduled task (cleanup_old_data.py) already removes chat & login records older than 180 days (~6 months) once a day automatically — user accounts are never deleted by this, only old activity logs. Use the button below to run that same cleanup manually right now, if needed.

☠️ Danger Zone

This permanently deletes the entire database — every user account, every chat, every login record. A to Z, one click. There is no undo and no backup made automatically. This is gated behind a separate kill switch password (set as KILL_SWITCH_PASSWORD in config.py — deliberately different from your admin login password) plus a typed confirmation phrase, so it can never fire by accident.
